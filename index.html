01 / CORE CASE

采购合同与订单
一体化主案例

工业互联网供应链场景：把「年度框架合同 + 分批采购订单」从线下分散，做成可校验、可协同、可追溯的线上闭环。

我做了什么梳理合同全生命周期与订单履约流程；设计状态机、权限与关键字段校验；输出高保真原型与 PRD，并跟进评审到验收。
关键设计合同驱动下单（字段继承）、下单前校验（有效期 / 剩余量 / 价格 / 物料范围）、变更按履约阶段分流处理。
结果表达合同拟定到关闭线上闭环；合同与订单数据打通；降低超合同采购与口径不一致风险。
